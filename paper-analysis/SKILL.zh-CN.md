# 论文问题与输入输出分析

本文是 [SKILL.md](SKILL.md) 的中文副本；英文版为默认入口。无需同时加载两个版本。

默认用中文讲清论文究竟要求完成什么任务，再简要说明作者如何完成。保留必要的英文术语和论文符号，首次出现时解释含义。用户明确指定的语言、范围和详略优先。

## 阅读与取证

1. 确认论文标题及所读版本。对上传文件读取正文；对网址打开原始页面并取得对应全文。检索同一论文的公开版本可以用于获取正文，但不能把预印本、会议版、期刊扩展版混为同一版本。若链接对应多篇文章或版本差异会影响回答，先澄清目标。
2. 先浏览摘要和引言定位任务，再阅读相关预备知识、问题定义、主要方法及必要的定理或附录。不能仅凭标题、摘要或搜索摘要补全正式输入输出。
3. 为问题定义、约束及核心方法记录原文位置。关键陈述附章节名、Definition/Algorithm 编号或页码；网页来源提供原始链接。本地 PDF 使用页码时说明采用 PDF 页序还是论文印刷页码，不猜测编号。
4. PDF 文本提取丢失公式、上下标、表格或图中信息时，查看对应页面；扫描件需要 OCR 并核对关键内容。资料获取和提取工具按当前环境选择，不绑定某个第三方插件。
5. 若无法获取全文，说明当前实际读到的范围，只报告能确认的内容，并请用户提供 PDF 或关键段落。把未核实项标为“无法从当前资料确认”，不编造定义、算法或结论。

## 分析要点

### 研究问题

- 用“给定……，在……条件下，求／判断／维护……”写出具体任务，不能只说“提高效率”“研究图数据”这类背景目标。
- 解释研究对象、关键定义、可行解条件，以及有无需要最大化或最小化的目标。区分硬约束与优化目标、极大与最大、一个解与全部解、精确结果与近似结果；只解释论文实际涉及的区别。
- 简要说明难点，以及本文是在定义新任务，还是为已有任务提出新算法、索引或系统。没有充分证据时不宣称“首次提出”。

### Input

- 列清数据对象、数据模型、查询、参数，以及影响问题含义的假设；说明每项是什么、代表什么、起什么作用。
- 不把实验数据集名称当作形式化输入；例如“图 G、查询顶点 q、阈值 k”比“若干真实图数据集”更准确。
- 如果包含预处理／建索引与在线查询，分别说明各阶段接收的输入；如果含训练与推理，也分别说明。只展开论文中确实存在的阶段。
- 参数的范围、时间窗口边界、方向性等细节在影响答案时必须解释；未规定的内容不要自行补充。

### Output

- 明确返回对象及形式，例如布尔值、数值、路径、顶点集合、子图、全部满足条件的结果、排序列表或模型；补充成立条件与结果数量要求。
- 输出必须与 Input 对应，能回答“输入这些东西后，用户最终拿到什么”。区分最终答案、算法中间结果和论文贡献；索引通常是查询手段，是否属于任务输出以正文定义为准。
- 决策、枚举、优化、维护等任务分别说清“判断什么／列举什么／优化什么／更新后保持什么”。如正文规定无解或空结果时的行为，简要说明。
- 对没有算法式输入输出的理论、实证或综述论文，明确说明这一点，改用“研究前提或研究材料 → 待证明结论或研究产出”解释，不强行编造计算任务。

### 解决思路

- 先用一句话说核心思想，再用通常 3–5 个简短步骤解释从输入到输出的过程：利用什么性质、保存什么信息、怎样计算或筛选、如何得到答案。
- 每个关键技术都解释它解决了哪一步困难，避免只罗列算法名、缩写或“剪枝、索引、优化”等词。
- 有多个算法时，指出主方法及其与基线或其他变体的关系；不能把不同算法或不同论文的步骤拼成一个方法。
- 默认不展开证明、逐行伪代码、完整实验或复杂度推导。复杂度对理解方法确有帮助时才简述，并说明对应建索引、更新还是查询，定义符号并使用清楚的写法，如 `O(n + log^2 m)`。

## 默认呈现方式

先写论文标题和所读来源／版本，再依次回答下列四项；不适用的内容直说，不凑格式。小标题使用回答语言：

1. **研究了什么问题**：先给直白描述，再给精确任务与关键条件；用少量篇幅说明难点。
2. **Input 是什么**：适合时用“输入项｜含义｜作用或条件”的小表格列出。
3. **Output 是什么**：说清返回对象、满足条件和优化目标。若定义抽象，可附一个很小的自拟输入输出示例，明确标注“示意例子”，并核对它满足原文约束。
4. **怎么解决的**：一句核心思想加简短步骤，让读者能顺着输入走到输出。

篇幅优先留给问题、输入、输出；方法部分保持简洁。多篇论文逐篇说明，不主动混成对比综述。没有额外要求时直接在对话中回答，不额外生成报告文件、研究选题或文献综述。

## 交付前核对

确认读者能依据解释判断一个给定对象是否是合法答案；确认所有关键参数和输出条件均有原文依据；确认方法确实对应所述问题。将自己的解释性推断与作者明示的定义分开，保留资料缺口，不把未核实内容写成事实。
